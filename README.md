# Ink & Ideas — React Blog Website

A responsive blog built with React and Vite.

## Features
- Blog homepage with featured story and article cards
- Category filters (All, Travel, Lifestyle, Technology)
- Read More article modal
- Newsletter email form with success message
- Responsive mobile layout

## Run locally
1. Install Node.js.
2. Open this folder in a terminal.
3. Run `npm install`.
4. Run `npm run dev`.
5. Open the local URL printed in the terminal.

## React concepts
`useState` manages category selection, selected article, email input and subscription state. `.map()` renders cards and `.filter()` selects category-matched posts.
